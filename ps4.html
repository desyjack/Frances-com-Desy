🎮 PS4 Remote Manager

Gerenciador de pacotes para seu PS4 na rede local. Envie somente arquivos que você tem direito de instalar.

Console

O Remote Package Installer deve estar ativo. Uma página HTTPS pode ser impedida de acessar este serviço HTTP pelo Chrome.

Adicionar pacotes

Cada pacote será enviado em uma requisição separada. O botão de envio não espera a instalação terminar.

Link de página ESPFile

A validação do código ocorre no ESPFile. Esta versão não extrai automaticamente o link; após acessar a página, copie o link direto do PKG para o campo acima. Não compartilhe códigos privados com serviços desconhecidos.
